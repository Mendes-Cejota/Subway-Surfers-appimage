# Subway Surfers AppImage

Este repositório disponibiliza o jogo Subway Surfers empacotado no formato AppImage para Linux, configurado para execução offline e sem anúncios.

## Instalação e Integração

Recomenda-se o uso do **Gear Lever** para gerenciar e integrar o aplicativo ao menu do sistema:

1. Baixe o arquivo `Subway_Surfers-1.1.0-x86_64.AppImage` na seção **Releases** deste repositório.
2. Abra o Gear Lever e arraste o arquivo `.AppImage` baixado para dentro da janela do programa.
3. Clique em **Mover para o menu de aplicativos** para concluir a integração.
